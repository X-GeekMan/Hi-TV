# Hi TV

Hi TV is a secondary development of [Null_](https://github.com/Null9797)’s [Halo TV](https://github.com/Null9797/halo-tv). **Current author: BenBen.** Halo TV itself builds on the open-source [Aerial](https://github.com/pengchujin/aerial-tv) project. This is an unofficial release; upstream copyright notices and the MIT license are retained.

The full app targets Android 5.0+ (Standard or Guard). Lite uses a separate package for Android 4.0–4.4 (beta).

Build with JDK 17 and the Android SDK:

```bash
./gradlew :app:assembleStandardRelease :app:assembleGuardRelease :lite:assembleRelease
```
